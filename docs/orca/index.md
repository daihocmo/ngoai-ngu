# Phương pháp Orca

Đây là bản lưu trữ hướng dẫn tự học ngoại ngữ được trích từ cộng đồng Discord [Ngoại ngữ phim và game](https://discord.com/invite/64PNZj69kj). Đây là phương pháp tự học ngoại ngữ thông qua comprehensible input và immersion (Dựa trên MIA hay Mass Immersion Approach). 

- [Giai đoạn 0](giai-doan-0.md): Một cái nhìn tổng quan về việc *học* ngoại ngữ. Đọc để hiểu cơ bản về các giai đoạn bên dưới đây.
